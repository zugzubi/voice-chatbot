# Voice-Enabled Deep Learning Chatbot

An academic project: a voice-enabled chatbot that listens to the user through the browser
microphone, converts speech to text using the **Web Speech API**, classifies the user's
intent using a **Bidirectional LSTM neural network** built with TensorFlow/Keras, and
speaks the response back using **Speech Synthesis**.

> The chatbot's intelligence is a genuine Deep Learning model — not keyword matching,
> not `if/else` rules, and not an external LLM API.

---

## Objective

Demonstrate the end-to-end pipeline
**Voice → Speech Recognition → Text → Deep Learning intent classification → Response → Text-to-Speech**
in a single, publicly deployable web application.

---

## Technologies Used

- **Python 3.11**
- **TensorFlow / Keras** — BiLSTM intent classifier
- **scikit-learn** — label encoding and train/val/test split
- **Flask** + **Gunicorn** — REST API and web server
- **HTML / CSS / JavaScript** — modern responsive UI
- **Web Speech API** (`SpeechRecognition`, `SpeechSynthesis`) — voice I/O in the browser

---

## Dataset

- File: `data/intents.json`
- **19 intents** (greeting, goodbye, thanks, about_bot, help, college, courses,
  admission, timetable, attendance, exams, fees, library, hostel, placements,
  contact, location, working_hours, technical_support, fallback)
- **~180 training patterns** total
- Split: **70% train / 15% validation / 15% test**, stratified by intent
- The dataset was hand-written for the college-domain use case

## Model Architecture

```
Input text
   ↓ lowercase
Tokenizer (Keras) → integer sequences
   ↓ pad_sequences (max_len=20)
Embedding(vocab, 64)
   ↓
Bidirectional(LSTM(64, return_sequences=True))
   ↓
GlobalMaxPooling1D
   ↓
Dense(64, ReLU) → Dropout(0.3)
   ↓
Dense(num_intents, Softmax)
   ↓
Predicted intent + confidence
```

If confidence < **0.50** the backend returns the `fallback` intent response
("I'm not completely sure I understood that. Could you please rephrase your question?").

---

## Speech Recognition

The browser's `SpeechRecognition` (Chrome/Edge: `webkitSpeechRecognition`) captures
microphone audio and returns the transcribed text on the `onresult` event. The
transcript is displayed to the user and automatically POSTed to the backend.
No audio ever leaves the browser — only the transcribed text.

---

## Methodology

```
Voice
  ↓ Web Speech API (browser)
Text
  ↓ lowercase + tokenize + pad
Deep Learning model (BiLSTM)
  ↓ softmax over intents
Predicted intent + confidence
  ↓ threshold check
Response chosen from intents.json for that intent
  ↓
Displayed in chat + spoken via SpeechSynthesis
```

## Run Locally

```powershell
# 1. create & activate a virtual environment (optional but recommended)
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. install dependencies
pip install -r requirements.txt

# 3. train the model (creates files under models/)
python train.py

# 4. start the web app
python app.py
# open http://localhost:5000 in Chrome or Edge (Web Speech API required)
```

### API

```
POST /predict
Content-Type: application/json
{ "message": "What courses do you offer?" }

→ { "intent": "courses", "confidence": 0.94, "response": "...", ... }
```

Other endpoints:
- `GET /health` — liveness probe
- `GET /api/info` — model metadata + training metrics

## Deployment

Two easy free-tier options are pre-configured.

### Option A — Render (recommended)

1. Push this folder to a **public GitHub repo**.
2. Go to <https://render.com> → **New +** → **Blueprint** → point at the repo.
3. Render reads `render.yaml`, installs `requirements.txt`, runs `train.py`, then
   starts gunicorn. You get a public HTTPS URL like `https://voice-chatbot.onrender.com`.

> The free plan cold-starts after inactivity; the first request may take ~30s.

### Option B — Hugging Face Spaces (Docker or Gradio-style Flask)

1. Create a new **Space** → SDK: **Docker**.
2. Push these files, plus a small `Dockerfile`:
   ```dockerfile
   FROM python:3.11-slim
   WORKDIR /app
   COPY . .
   RUN pip install --no-cache-dir -r requirements.txt && python train.py
   ENV PORT=7860
   CMD ["gunicorn", "app:app", "--bind", "0.0.0.0:7860", "--workers", "1", "--threads", "4", "--timeout", "120"]
   ```
3. Space builds and gives you a public URL like
   `https://huggingface.co/spaces/<user>/voice-chatbot`.

### Option C — Railway

1. New Project → Deploy from GitHub → select this repo.
2. Railway auto-detects Python + the `Procfile`. Add a build step
   `pip install -r requirements.txt && python train.py`.

Whichever platform you pick, paste the resulting URL under **Deployment** in the report.
